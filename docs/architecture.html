Complete MLOps Infrastructure on Google Cloud

Google Cloud Platform Terraform Module

Executive Summary

This Terraform module deploys a comprehensive Vertex AI MLOps platform on GCP. It provisions a Feature Store with entity types for online/offline feature serving, an Artifact Registry repository for model containers, prediction endpoints with Private Service Connect, Workbench notebook instances with optional GPU accelerators, Tensorboard for experiment tracking, and a dedicated service account with least-privilege IAM roles. All components are connected via VPC networking for private connectivity.

Component Breakdown

Feature Store (google_vertex_ai_featurestore)

Managed feature store with configurable online serving (fixed node count). Entity types created via for_each with name, description, and labels. Supports online and batch serving for feature retrieval during training and inference.

Artifact Registry (google_artifact_registry_repository)

Docker-format repository for storing model artifacts, training containers, and serving images. Created per module with region-specific location.

Prediction Endpoints (google_vertex_ai_endpoint)

Vertex AI endpoints for model serving with optional Private Service Connect via VPC network. Each endpoint has a display name, description, and labels. Supports multiple deployments per endpoint.

Workbench Instances (google_workbench_instance)

Managed notebook instances for ML development. Configurable machine types, optional GPU accelerators, PD-SSD boot and data disks, VPC network integration, and dedicated service account.

Tensorboard (google_vertex_ai_tensorboard)

Managed Tensorboard instance for experiment tracking, metric visualization, and model comparison across training runs.

Service Account & IAM

Dedicated service account with auto-assigned least-privilege roles for Vertex AI workloads including AI Platform User, Storage Admin, BigQuery Data Editor, and related roles.
